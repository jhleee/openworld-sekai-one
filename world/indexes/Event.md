# Event

- [일곱 맹약의 체결](../wiki/EVT-COMPACT.md) — 맹약력 6년, 일곱 피난 공동체가 구조와 자원 분배의 조약을 체결했다.
- [푸른 제방의 밤](../wiki/EVT-FLOOD.md) — 맹약력 307년 벨수의 제방 붕괴 때 구조대가 세 마을을 대피시켰다.
- [하늘의 파열](../wiki/EVT-FRACTURE.md) — 맹약력 0년, 하늘의 연속된 막이 갈라지고 잔해가 대륙에 떨어진 사건.
- [숲가의 임시 재측량](../wiki/EVT-HUSH-SURVEY.md) — 맹약력 312년 숲가 주민들이 경계 기억과 새 도면을 나란히 살폈다.
- [접힌 성벽의 경첩 정비](../wiki/EVT-ORVAN-REPAIR.md) — 맹약력 311년 오르반이 접힌 성벽의 피로한 경첩을 정비했다.
- [검은 눈 고개 전투](../wiki/EVT-PASS.md) — 맹약력 309년 이상 한파에 내려온 서리늑대 무리를 구조대가 몰아냈다.
- [남은 물품의 임시 교환](../wiki/EVT-TRADE-PARTIAL.md) — 312년 세 지역의 운반자들이 남은 물량 일부를 먼저 교환했다.
- [초여름 교역 중단](../wiki/EVT-TRADE-PAUSE.md) — 312년 벨수와 카르드, 무음림을 잇는 약속된 교환이 늦어졌다.
