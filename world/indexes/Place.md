# Place

- [아르켄 대륙](../wiki/LOC-ARKEN.md) — 깨진 하늘의 잔해를 둘러싸고 일곱 지역이 교역하는 대륙.
- [에스텔 군도](../wiki/LOC-ESTEL.md) — 등대 협약으로 연결된 남쪽 항구와 부유 암초의 군도.
- [무음림](../wiki/LOC-HUSH.md) — 소리를 저장하는 수목과 오래된 계약이 남아 있는 동부 숲.
- [카르드 고개](../wiki/LOC-KARD.md) — 북부 철광과 남부 곡창을 잇는 산악 통로.
- [루멘 자유시](../wiki/LOC-LUMEN.md) — 중앙 분지의 수로와 렌즈 공방이 모인 자유시.
- [사헬 유리사막](../wiki/LOC-SAHEL.md) — 하늘 잔해의 열로 모래층이 유리로 굳은 남부 지역.
- [수리 마을의 공동 우물마당](../wiki/LOC-SURI-WELL.md) — 사헬에서 물 배분과 부품 학습이 이루어지는 작은 공동 작업 공간.
- [갈대섬 구조 장비창고](../wiki/LOC-VELSU-STORE.md) — 벨수 연맹이 구조용 밧줄과 방수천을 보관하는 공동 창고.
- [벨수 수계](../wiki/LOC-VELSU.md) — 범람원과 갈대섬을 묶는 어업·뱃길 공동체.
