# 이전 하네스의 경험

문서 ID: ARKEN-LESSONS-001 · 기준일:2026-11-17

이전 회백해는 24회 중10성공14실패였고 개발 중 코드가 바뀌었다. 최종154기록18본문과 Python94개는 이전 구현의 증거이며 새 저장소의 통과 결과가 아니다.

단회 회합의 열린 Fact, 최초 관측·추정 사망의 확정 기간화, Article 없는 작업, 본문 재복사 손상, 동일 실패 초안 무한 재작성, 행정 기록 편중을 겪었다. 새 구현은 사건/상태 구분, required_paths, 범위 제한, 본문 일치, 재작성 한도, 넓은 지리·생활·생태 부트스트랩으로 대응한다.

키워드는 경고만 남긴다. 같은 모델의 독립 역할도 공통 오류가 있다. 기존 API 키·DB·비밀번호·실행 로그 원문은 복사하지 않는다. 정사 버전은 Git이 관리한다.
