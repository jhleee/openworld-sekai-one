# Terra 중심 장기 확장 시험

문서 ID: ARKEN-EXP-20261117 · 버전:1.0 · 기준일:2026-11-17 · 검토자:Codex · 상태: 로컬 실험 완료

## 결과

사용자의 비용 절감 요청 이후 새 생성·검토는 Terra로 전환했다. Luna는 당시 선택 가능한 모델 목록에 없어 사용하지 않았다. Sol 레인의 미완료 초안은 기존 두 검토를 재사용하고 마지막 위키 검토만 Terra로 수행했다.

| 구분 | 승인 단위 | 작은 확장 작업 | 최종 본문/기록 | 증가 |
|---|---:|---:|---:|---:|
| Terra 실험 | 초기1사이클 + 절약형3배치 | 10 | 73/73 | +20 |
| Sol 잔여 실험 | 1사이클 | 1 | 55/55 | +2 |

두 실험은 같은53문서에서 갈라진 별도 브랜치다. 최종 문서수를 합산해128개 세계라고 하지 않는다. Terra 최종 커밋은 3102fb267081b2caec172fcbde19cfddcaa71aa6, Sol 잔여 커밋은 5b0907c486d93fb7d5a25a8861c615e5c0e6adbc다. 기본 브랜치의53문서 정사는 변경하지 않았다.

절약형 구간은 작은 작업3개씩 묶어6개문서 단위로 검토했다. 9작업·18신규본문에 독립 검토15회(초회3세트9회, 재검토2세트6회)를 수행했다. 첫 절약형 배치에는 작성 하위에이전트3개도 사용했으나 이후에는 실행 담당자가 순차 작성하여 초기문맥 반복을 줄였다. 각 검토는 fresh context이며 같은 Terra 모델이므로 판단 오류의 상관관계가 남는다.

전체 저장된 검토 응답은21개: approve20, revise1. 최종 승인 영수증5개를 과거 Git 파일과 기준 부모커밋으로 다시 계산해 모두 검증했다. 최종 정적 오류는 양쪽0이며 키워드 경고는 Terra6·Sol5다. 양쪽에서 Python40개 테스트와 색인 재현 검사가 통과했다. 검토 응답 수가 모델의 내부 도구 호출 수나 토큰 수는 아니다. 토큰·금액·정확한 총 경과시간은 미계측이다.

## 실제로 발견한 문제

1. **기금 상태의 불일치**: 기존 조직은 도시 분담 구조기금을 만들려는데 신규 문서가 이미 운영하는 것으로 읽혔다. 초기검토 warning으로 남겼고 후속배치에서 임시분담장부와 제도적 기금을 구별했다.
2. **작업 범위 누락**: 자동색인6개가 task 허용경로에 빠졌다. wiki 검토자가 blocker로 차단했다. 원래 파생출력에 속하는 색인을 명시하고 세역할 재검토를 받았다. 정책/검사 코드는 확장하지 않았다.
3. **같은 해의 사건 선후 표현 한계**: 교역 중단과 부분재개가 모두312년인데 after 검사가 엄격한 연도 증가를 요구해 정적오류가 났다. 모델은 after를 제거했고 본문에는 지연 뒤 재개라는 순서를 유지했다. 운영자가 이 손실을 발견해 lost_structured_constraints로 명시하고 세역할이 재검토했다. 이는 해결이 아니라 수용된 미검증 제약이다. 생성연표에서 부분재개가 중단보다 먼저 나열되는 문제도 남아 있다.

## 내용 검수

제방 노동자·토마의 조카·환기갱 견습·약초 건조 일꾼에게 독립된 생계와 선택을 부여했다. 무음림 재측량으로 채취와 수입이 줄고, 그 부담이 가호 협상·세 지역 교역 지연·제한적 교환으로 이어진다. 부분재개는 임금 손실과 위험갱도 문제를 자동으로 없애지 않는다. 오르반 계약의 공개지지 금지 여부는 주장으로 남겼다. 새로운 능력으로 기존 비용을 면제하지 않았다.

새 문서 다수가 노동·조정·교역이라는 비슷한 축을 공유한다. 이번 시험은 누적 인과와 제약 보존에 초점을 맞췄으므로 모험·전투·신앙·유물 탐험의 폭이 충분해졌다고 평가하지 않는다. 토큰 절감 배치 검토는 변경집합을 크게 만들어 개별 결함을 놓칠 위험이 있다.

## 증거와 재현

[audit.json](audit.json)은 검토·경고·영수증 재검산 결과, [progress.json](progress.json)은 최종분류와 크기다. terra/sol 하위폴더에는 실제 task, 원본 역할검토, manifest가 있다. Sol 초기 knowledge 검토의 원래 agent ID는 세션 재시작 뒤 복구하지 못해 manifest에 그 한계를 명시했다. ID를 지어내지 않았다.

브랜치: experiment/terra-long, experiment/sol-long. 각 브랜치를 별도 worktree에서 열고 tools/validate.py, tools/index.py --check, unittest를 실행한다. 키와 .runtime 로그는 Git에 포함하지 않았다. HMAC 재검증에는 로컬 운영자 키가 필요하며 외부 공개하지 않는다.

## 판정과 후속 작업

작은 문서 묶음을 누적하고 코드검사·독립검토·수정·서명기록을 유지하는 실험은 완료했다. 원래 목표였던20개 개별사이클은 비용 절감 요청으로11개 작은작업/5승인단위로 변경했다. 수백회 장기 안정성을 입증한 결과가 아니다. Terra와 Sol의 과제가 달라 성능 우열을 비교할 수 없다.

다음 우선순위는 시간의 정밀도와 상대순서를 분리하고, 동일연도 연표를 부분순서로 표시하는 것이다. 그다음 서로 다른 지역의 실험을 합칠 때 중복·관계·전체정합성을 다시 검토한다. 이 실험 결과를 자동으로 기본 정사에 합치거나 GitHub에 게시하지 않았다.
